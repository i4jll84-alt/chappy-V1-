# 保存済み合成モデル検証の監視

第5段階の初期監視を、既存の合成モデル研究結果へ広げる。
実市場モデルの劣化や利益の優劣を認定する機能ではない。
新しい学習・推論・モデル選択・バックテストは実行せず、保存された検証結果だけを読む。
最終評価の消費記録や学習済みモデルを変更しない。

## 実行

```powershell
.\.venv\Scripts\python.exe -m trading_system.cli monitor-research --max-mse-ratio 1.2 --max-mean-shift 1 --output data/monitoring/research-current.json
```

既定の入力は `data/research/model-result.json`。`--result` で別の保存結果を指定できる。
出力は研究ディレクトリ外のJSONに限定する。Excel・APIキー・ネットワークは不要。
重複キーや非有限定数を含むJSONは拒否し、読取失敗時に本文や例外詳細を表示しない。

2つのしきい値は必須の正の有限数。上記1.2と1は機能検証用の例であり、
実市場に適切な値や統計的有意性を示す値ではない。
`--minimum-rows` は学習参照・評価の必要行数（既定20、最低2）であり、
統計的な検出力や独立した標本数の保証ではない。

## 監視項目

保存済みの5・10・20・60取引セッションの全期間を対象にする。暦日数ではない。
結果・モデルのハッシュ、入力の対応、評価対象のキー・時刻・特徴量の並びを確認する。
ハッシュは誤変更の検知用で、第三者による真正性の認証ではない。
元シナリオから対象行の欠落とラベルの対応を検査する。特徴量は保存値を用い、
参照した価格・時刻とハッシュを確認するが、各特徴量の計算式を再実行する検証は行わない。

保存済み予測と正解ラベルからMSE・MAE・方向一致率を照合する。
同じ評価対象の採用モデルMSEを基準モデルMSEで割り、指定しきい値を超えたら注意とする。
基準MSEが0の場合、両方0なら比率1、採用側が正なら比率nullと注意を返す。
この比較は同一検証期間の基準対比であり、運用中の時系列的な劣化を証明しない。

入力変化は、保存された採用モデルの学習対象と最終評価対象の特徴量平均を比較する。
学習側の母標準偏差で平均差の絶対値を割り、指定しきい値を超えた特徴量を注意とする。
学習側の標準偏差が0の場合は、平均も同じなら0、平均が異なればnullと注意を返す。
評価側を使って基準を作り直したり、成績を見て期間を選び直したりしない。
この指標は平均の移動だけを見るため、分散・裾・依存関係などの変化は見逃し得る。

観測時刻は実行時UTCが既定。`--observed-at` でタイムゾーン付き時刻を明示できる。
評価や正解ラベルがまだ利用できない時刻では、その期間の指標を表示しない。
未来の行だけを除外して、都合のよい部分評価へ変えることもしない。
これは保存結果の検査時計であり、過去の実市場PITを再現する仕組みではない。

## 判定と制限

終了コード0=`observed`、3=`attention`、2=入力・読取エラー。
注意なしでもモデル採用・実運用開始・発注を許可するものではない。
注意が出ても自動再学習・モデル差替え・停止解除をしない。
合成データでの監視機能検証であり、実市場の継続観測やモデル劣化検知は今後の課題。
監視しきい値の調整を最終評価結果への反復的なモデル最適化に利用しない。

## 保存済み結果での確認

既存の合成研究結果（約13.57 MB）を、新しい学習や推論なしで読み取った。
各予測期間の評価行数は100。しきい値を誤差比率1.2・平均移動1とした検証結果は以下。

| 予測セッション数 | 学習参照行数 | 基準に対するMSE比率 | 判定 |
|---|---:|---:|---|
| 5 | 548 | 0.9094 | 検査範囲の注意なし |
| 10 | 538 | 0.8599 | 検査範囲の注意なし |
| 20 | 518 | 1.0000 | 検査範囲の注意なし |
| 60 | 438 | 1.7060 | 誤差比率のしきい値超過 |

特徴量平均の移動はこの例のしきい値を超えなかった。全体は注意あり、終了コード3。
これらは合成検証の比較結果であり、実市場の推奨モデルや有意な改善を示さない。

固定観測時刻で別プロセスから2回実行し、JSONのバイト一致を確認した。
研究ディレクトリ内の86ファイルは、実行前後のファイル集合とSHA-256がすべて不変。
結果はGit対象外の `data/monitoring/research-current.json` と `research-repeat.json` に保存した。
修正後も同じ確認を行い、評価日前の時刻を与えた追加実行では、4期間すべての指標が
未算出になることを確認した。追加結果は `research-before-evaluation.json` に保存。

ゼロ誤差・定数列、しきい値境界、入力不変、学習・推論・評価記録の再実行禁止を検査。

元シナリオに対する行の不足として拒否できることを確認した。

実装・独立レビューの担当設定はGPT-6.1 Sol / HighとGPT-6 Astra / High。
内部で実際に使用されたモデルを独立確認したという意味ではない。
最終レビューに未解決の重大指摘はなかった。
