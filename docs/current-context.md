  重複する通知設定を作らず、16時停止自体を通知やCodexの稼働に依存させない。
- 保存先: https://github.com/i4jll84-alt/chappy-V1- （公開リポジトリ）。
- ローカルの既存`master`をGitHubの`main`に対応付ける。通常のpush先はupstreamを使い、
  他のローカルブランチやバックアップrefは送信しない。
- コード・仕様・設定・進捗・引き継ぎ情報を変更した場合、適切な検証と送信対象の確認後に
  コミット・pushする。送信成功はGitHub側のコミットIDと照合して確認する。
- 認証情報・取得データ・Raw・DB・Parquet・仮想台帳・ログ・バックアップ・テスト一時生成物は
  送信しない。`.env.example`はキーが空の説明用ファイルだけを保持する。
- 既存変更を消さず、force pushや全refのpushをしない。同期失敗は未同期として報告する。
- GitHubから取得したソースだけでは、ローカルの取得履歴・台帳・環境変数は復元できない。
- `*-win11u7270.*`という既存の複製ファイルは削除せず保持しているが、
  運用手順・基本設定は接尾辞のないファイルを基準にする。
