# RSS継続取得とペーパートレード動作確認

## 開始と停止
1. マーケットスピードIIへログインし、ローカルの `Documents/RakutenRSS/RSS接続確認.xlsx` をExcelで開く。
2. ExcelのRSS表示を「接続中・発注不可」にする。
3. デスクトップの「RSS接続確認して開始」を開く。
4. 16時に取得を止めて保存・照合後に自動終了する。途中で終了する場合は「RSS常時取得を停止」を開く。保存完了まで待つ。Ctrl+Cでも停止できる。

起動中のPC、Excel、マーケットスピードIIが必要。PC起動だけでは取得は始まらない。
標準で2秒の待機を挟み、5回ごとに保存する。COM読取時間を含むため厳密な2秒間隔ではない。
日本時間16時まで繰り返す。自動ログイン、自動再起動、休場日判定、PCスリープ解除、
毎朝の予約起動は設定していない。停止要求は標準設定では通常約1分以内に確認されるが、
保存・最終照合時間はデータ量に依存する。ウィンドウの強制終了より停止用ショートカットを使う。

保存先はプロジェクトの `data/rss-continuous`。
`status.json` にPID、直近更新、読取件数、注意件数、仮想残高を保存する。
停止時・異常終了時は状態を記録するが、強制終了した場合はrunningが残ることがある。
表示だけを稼働証拠にせずPID・更新時刻も確認する。
Rawは `runs`、台帳は `store`、仮想取引は `paper.sqlite`。
Parquetは30サイクルごとと正常停止時に書き出す。DB/Rawの保存は各サイクル。
同じ保存先の二重起動はOSのファイルロックで拒否する。

## 仮想取引の範囲
実発注・証券口座への注文照会・注文取消は一切呼ばない。
実行するのはRSS専用3セルの読取とローカルファイルの更新だけ。
対象7203.T、仮想初期現金100万円、100株の買い→売りを1往復する固定接続試験。
読取可能な観測でシグナルを作り、表示時刻が進んだ後続の観測で仮想約定する。
1往復後は株価取得のみ継続する。同じ保存先で再起動しても再売買しない。
新しい試験を行う場合は別のdata配下フォルダーを明示する。既存台帳は消さない。

仮想手数料は片道10円、仮想滑りは不利方向5bps。実際の料金・約定条件を表さない。
値動きに基づく投資戦略や収益性の判定ではない。仮想約定には板・出来高・実約定の裏付けがない。
過去30秒以内の観測と表示時刻を検査するが、「現在日付」は約定日を保証しない。
RSS接続状態・提供元更新時刻・鮮度は引き続き未証明として記録する。
スリープ復帰後の過去データ再読込やエラー記録から仮想約定を作らない。

## 注意履歴の扱い
excel_not_ready等はRawとして保存し、次のサイクルで再度読取を試す。
エラーや古い表示時刻では仮想約定をせず、未完了の仮想シグナルを取り消す。
PCやExcelを勝手に再起動しない。データ破損・保存失敗・残高不一致では処理を停止する。
過去の欠損を補完せず、未完了runのsummaryも捏造しない。再開時に残存Rawを取り込み、
仮想処理は重複を除外して、未処理の復旧データでは約定しない。
