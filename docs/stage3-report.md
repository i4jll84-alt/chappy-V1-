# 第3段階: AI分析・予測モデルの初期基盤

**1. 工程名**

合成データによる、時点を守った特徴量・予測モデル・公平な評価の初期実装。
実市場データによるモデルの有効性や本番採用を判定したものではない。

第7.7節の条件を、固定された合成入力・候補モデルの範囲で確認した。
第7章全体の市場実用性や統計的優位性を確認したという意味ではない。

| 条件 | 今回の確認 |
|---|---|
| 各モデルが再学習可能 | ゼロ・訓練平均・Ridge・LightGBMの学習経路とパラメータを保存。独立再学習も検査 |
| 特徴量・予測値の再現 | 過去21セッションの出所・時刻・特徴量順序を保存し、モデル再読込み後の予測を照合 |
| 学習・検証履歴 | 20候補試行、途中状態・失敗・選択根拠を記録 |
| ベースラインと公平に比較 | 同じ評価対象、資金、保有期間、約定・費用制約で比較 |
| 未使用期間で評価 | 最終期間を選択から分離し、最終評価を一度だけ消費 |
| 過剰最適化監査 | 固定候補・固定改善基準・境界と提供時刻の監査。統計的有意性検定は未実施 |
| 不採用モデル結果保存 | 不採用の検証指標・予測・モデルを保持し、最終結果を見た再選択をしない |

**2. 使用したCodexモデル・推論設定**

- 特徴量・学習・評価パイプライン・CLI実装: GPT-6.1 Sol / High（継続担当エージェント）。

- 統括担当の接続実装もAstraが独立レビューした。

**3. 実装した機能**

5・10・20・60営業日先の翌寄付からのリターンを対象とし、過去価格の特徴量から予測する。
ゼロ予測、訓練平均、Ridge、LightGBMを比較する。最終期間をモデル選択に使わず、
学習・予測・不採用結果を保存する。予測の符号を第2段階のシミュレーターへ渡し、
同じ判断機会・保有期間・資金・費用で比較する。
詳細は[設計](model-research-design.md)を参照。

**5. 実行したテスト**

2026-10-23に`.venv/Scripts/python.exe -m pytest -q --basetemp .test-tmp/s3`、
`python -m ruff check .`、`python -m ruff format --check .`、`python -m pip check`を実行した。
新規テストは研究経路22件と比較接続13件。4予測期間のラベル、過去だけの特徴量と尺度、
LightGBMの再学習・再読込み、遅延ラベル、将来欠損、中断履歴、最終評価の一度限りの実行、
APIを使わないCLIを検証した。既存の第1・2段階も全体テストに含めた。
導入時にはLightGBMの実学習・モデル文字列再読込み・再予測を小さい合成入力で実行した。
2回の独立した学習でモデル全体と40件の予測が一致した。pip checkも成功した。

標準CLIを`data/research`の新しい実験記録で実行し、420合成セッション・2銘柄から、
5候補×4予測期間の20試行を保存した。各期間の最終予測は100件。
予測モデル、単純モデル、モメンタムの費用比較がすべて完走し、
`cost_evaluation_complete=true`となった。このフラグはシミュレーションが中断せず
評価できたという意味であり、利益や優位性を保証するものではない。

結果はGit対象外の`data/research/model-result.json`へ保存した。同じ保存先での再実行は
キャッシュを返し、出力バイト列が一致し、実験記録配下の全ファイルのSHA-256も不変だった。
この確認と、独立再学習の再現性テストは別の検証である。

- 入力SHA-256: `6e13489a28a9e7917d9e8a64d1cf907dd22b0b7522587dea0a637290527b9312`
- 結果SHA-256: `506d7af479e4029bf0aef34a01632a792340d9453889de2162adb17adf0c6f53`

この合成実験内の選択は5日Ridge(alpha=10)、10日LightGBM、20日訓練平均、60日LightGBM。
本番採用や実株価に対する推奨ではない。単純モデルを残す選択経路も実行された。

**7. 発見した問題**

検証ラベルの対象日だけで除外すると、後から提供された正解をモデル選択に使えてしまう。
提供時刻が最終学習の締切までであることも必要条件にした。
また、最終評価で将来の寄付欠損を見て取引対象だけを除くと選択バイアスになるため、
その場合は研究全体を拒否する。失敗した候補も選択前に履歴を保存する。
修正後のAstraレビューでは、この初期範囲に未解決の重大指摘はなかった。

**8. 未確認事項**

実市場の学習・最終テスト、金融危機等の実データ検証、統計的に有意な利益改善は未確認。
財務・信用需給・投資家・業種・出来高特徴量、CatBoost/XGBoost/LLM、独立下落予測器の
比較、実TOPIX超過・リスク調整後リターン予測は未実装。第1・2段階の実市場データ不足は継続する。

**9. 既知のリスク**

合成価格の学習成績は実際の市場での有効性を示さない。検証MSEの改善基準は事前に固定した
選択規則であり、有意性検定ではない。売買シミュレーションの不成立・停止も実行結果に残す。
企業行動を含む学習シナリオは初期範囲で拒否する。予測計算の遅延を再現しない。
再現性は固定ライブラリ・同じ実行環境の範囲。最終期間の保護はローカルの実験単位であり、
別ディレクトリ・別実験や手動編集による同じ期間の再利用まで防ぐものではない。
float64の計算範囲を超える極端な入力では実行が例外終了し、開始済みの試行記録だけが
残る場合がある。非有限値を正常な評価指標として保存することは許可しない。
