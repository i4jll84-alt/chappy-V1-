**7. 発見した問題**

時系列分割の初稿では、開発中の検証ラベルが最終未使用期間に到達する場合があった。
訓練サンプルだけでなく、境界をまたぐ検証サンプルも除外するよう修正し、回帰検証した。
信用売りのスリッページ後の担保判定、停止時の注文状態、対象一覧から外れた保有の
決済管理も修正した。未提供の終値を保有評価から担保判断へ間接的に流入させないよう、
必要な終値が判断時刻に利用できない場合は計算を停止する。
修正後のAstra独立レビューでは、この初期範囲に未解決の重要問題はなかった。

**8. 未確認事項**

実市場の全期間・全銘柄のバックテスト、実際の寄付の約定可能数量、過去の信用在庫・規制・
費用体系・権利履歴、実市場の急変期での頑健性は未確認。合成データでの損益を投資成績と

実TOPIX超過リターンは未算出で、合成比較指数の超過リターンと区別する。
時系列分割と探索記録はPython APIとして提供し、自動探索や学習は実施していない。

**9. 既知のリスク**

合成モデルは日次・明示ルールによる限定されたシミュレーションで、板の注文順位、
部分約定、実際の信用保証金/追証/受渡/税金を完全には再現しない。未知の権利や不足する
情報を推定で補わない。初回取得より前の情報状態は復元できない。
同日・同銘柄の分割と現金権利の併発、全保有が1株未満になる併合は拒否する。
分割後の単元未満株や約定不能な決済注文は、保有期限を超えて未決済となり得る。
最終未使用期間の保護はローカル実験単位であり、手動のファイル変更や別実験IDによる
同一期間の再利用を組織的に防止する機構ではない。
