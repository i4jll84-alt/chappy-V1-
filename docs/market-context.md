# 寄り前の市場環境と日経225先物

各朝のスイング判断では固定ルールで候補を選び、各群の候補に市場環境を加味した場合の買付・見送りを独立に記録する。各群の初期資金は200万円。買付の追加、入れ替え、保有期限の変更はしない。終値評価の純損益、費用、最大下落率は毎日同じ方法で計算する。

| 指標 | 出典・単位 | 朝に確認する変化 |
|---|---|---|
| JP10Y・DGS10 | 財務省とFREDの日本・米国10年国債利回り（%） | 前回の観測値との差（bp） |
| USDJPY | ECBの同じ日の円／ユーロとドル／ユーロから計算した円／ドル参考値 | 前回参考値からの変化率。上昇は円安 |
| SP500・NASDAQCOM | FREDのS&P 500・NASDAQ総合終値 | 直近の公表済み観測値の騰落率 |
| NK225F | 大阪取引所日報、日経225先物ラージの期近。円建て、競争売買 | 同じ限月・同じ夜間セッションの始値から終値までの変化率 |

公表予定時刻は実際の取得時刻とは異なる。大阪の日報は翌営業日の9時ごろに公表されるため、朝は直前の夜間取引より前の資料となる。日報の取引日は取引所の営業日表記。取引時刻や配信元の実公表時刻を推定しない。先物の現物代替や限月間の価格差の連結は行わない。日報に夜間四本値を確認できないとき、取得エラー、満期超過は記録する。指標ごとの現地日付（東京、ニューヨーク、ECBは欧州時間）を基準に、経過4暦日を超えた観測、または日次系列で間隔が7暦日を超えた変化は判定対象外。祝日や配信遅れで各系列の最新日が異なり得る。

国内株と信用情報は従来の選定日締切を使う。市場指標だけは判断当日の保存完了時刻までの版を使う。買付日9時以降は朝の判断を作成できない。原本、取得日時、URLとSHA-256はローカルの data/swing-forward/macro/ に保存する。公表実時刻が不明なら null とする。

各群の market_review は manifest_sha256、indicators（usable 全系列）、reason（根拠・反証・情報不足）、defer（その群での新規買いを見送るコードごとの理由）で構成する。見送る根拠が十分でなければ空の辞書とする。未取得、古い値、推測した企業の為替感応度だけで見送らない。影響を一律の買い／売り点数に変換しない。

引け後は close.json の macro_counterfactual で、同じサブエージェントの注文を使った比較口座に有効な見送りを適用する。欠測や回答不備は区別し、その日には追加の見送りを適用しない。比較対象は同じ固定ルール側の口座。レビューには評価日数・不足日数・見送り数・累積純損益差を記録する。過去資料の一括取得による回顧試算と、実際の寄り前保存を使った前向き検証を区別する。

参照元は[財務省](https://www.mof.go.jp/jgbs/reference/interest_rate/index.htm)、[FRED](https://fred.stlouisfed.org/series/DGS10)、[ECB](https://data.ecb.europa.eu/methodology/exchange-rates)、[大阪取引所日報](https://www.jpx.co.jp/markets/statistics-derivatives/daily/index.html)。

## 11月4日～12日の回顧試算

過去のサブエージェント注文を確定済みの連続7営業日すべてで使用した。初期資金は各200万円、建玉なし。1銘柄100株、片道の仮定は手数料10円とスリッページ0.05%。買付から6営業日後に始値で決済し、最終日まで保有する株は終値評価。配当と税は含まない。

市場判断用に既存の買付候補を匿名化した。GPT-6 Astra（高推論）へ寄り前の入力を1日ずつ時系列順に渡して各日の回答を確定し、後日の市場指標、銘柄対応表、実現損益を見せずに評価した。一括入力での参考試行も別に保存し、時系列試行を主結果とした。元のルールだけの口座は、各日の台帳と費用後損益・評価額・費用・最大下落率を照合した。

|---|---:|---:|---:|---:|---:|
| 現行 | −60,536.05円 | ＋757.50円 | ＋61,293.55円 | 9→5 | 3.22%→0.15% |
| 移動平均・売買代金・信用の3条件追加 | −4,001.10円 | −4,001.10円 | 0円 | 5→5 | 2.70%→2.70% |

現行で見送った4件のうち、期間内に決済した元の取引は損失2件（計37,099.30円）と利益1件（5,015.05円）。残り1件は最終日の終値評価。市場判断を加えた口座の確定損益は−781.65円、評価損益は＋1,539.15円、未決済3件。最初の3件を見送った日は国内金利・先物の鮮度が基準外で、米国株の下落と各候補の5日線割れ・売買代金の縮小を主な理由とした。残る1件では日経225先物の下落も理由に含まれた。3条件追加群の信用入力は7回のうち1回だけ両日分がそろった。

国内金利と先物を含む6指標をすべて参照できたのは6営業日。履歴は後日取得版で、保守的に米3系列は東京のエントリー日の3平日前まで、ECBは前日以前、日本金利と先物日報は選定日より前の資料を使用した。日米金利・米株・為替の系列ごとに観測市場の暦日で鮮度を計算した。これは当時の配信・訂正履歴を保証しない。少数の見送りと投資額の差を含む比較で、先物単独の寄与と長期の優位性は未評価。

再計算には scripts/swing_market_replay.py を使う。ローカルの data/offline-verification/swing-market-replay-20261113/ に入力とハッシュ、原本、判断を保存。日別結果と期間末集計は chronological-results.json。既存4口座のルールへの採用は前向き検証で評価する。
