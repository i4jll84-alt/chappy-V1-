## 8. 発見して修正した問題

レビューで、同一取得内に異なる実適用日（Date）が混在する場合の検査不足を見つけ、品質エラーとして検出するよう修正した。キャッシュ済み取得でも常にDBからParquetを再出力し、DBを正として扱うようにした。HolDivが不正な場合、東証営業日フラグをfalseへ変換せずnullとして品質問題に残すようにした。テストのRawファイルglob依存を安定化し、過去時刻を使ったPITテストの時刻逆転も修正した。初期テストの不具合2件は修正済み。

## 9. 途中の検証上の問題

実装担当の初回pytestでは一時フォルダーの権限問題により47件のsetup errorが発生した。ワークスペース内の専用basetempを指定して再実行し、参照データ単体の56件が成功。その後、親担当が統合結果204 passed・3 skippedを集計し、実APIを含む最終実行では207件すべて成功した。初回の環境起因エラーを最終テスト成功と混同していない。
