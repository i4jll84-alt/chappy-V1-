# RSS開始前の接続確認
デスクトップの「RSS接続確認して開始」を使用します。
マーケットスピードIIへのログイン、対象Excelの「接続中」「発注不可」、場中の株価時刻の更新を本人が確認します。
チェックは自己確認です。接続状態や鮮度を自動検証したことにはなりません。
全項目の確認後、既存の読み取り専用プローブで3件を検査します。失敗時は開始しません。記録はdata/rss-start-checksに保存します。
既存取得が稼働中なら二重起動しません。確認中に新しい停止要求が届いた場合も開始しません。
既存のStop、Status、Check操作は維持しています。実注文、アプリの自動ログイン、接続ボタン自動クリックは行いません。

## スマホからの操作（未設定・未検証）
確認画面の「スマホ遠隔操作の設定ページ」から https://remotedesktop.google.com/access を開きます。
本人のGoogleアカウントでサインインし、画面の案内に従いホストを設定、本人がPINを入力します。PINをチャットやファイルに保存しないでください。
スマホから同じアカウントでアクセスし、PCのExcelを確認します。発注不可を維持します。
外出前にスマホのモバイル通信から接続できるか試してください。PC電源・ネット接続・スリープしていない状態が必要です。
スマホ通知、スリープ設定、アプリ一括起動、接続自動判定は今回未実装です。

## 検証
PowerShell構文チェック、チェック未完了時のボタン無効・全確認時有効・解除時無効・取消の非開始を確認。
稼働中Startの二重起動拒否を実確認。既存RSSテスト48件成功。
GUI実表示・本人の接続操作・新規取得開始・スマホ遠隔接続は未検証。
## 16時停止（2026-10-27）
取得プログラム自身がAsia/Tokyoで16時を判定し、保存・照合して終了します。
開始時の実行プロセスにはRemoteSignedを指定し、PC全体の実行ポリシーは変更しません。
開始ショートカットを15:59以降に開いた場合は、事前読取が16時を越えないよう、
Excel確認を省いてオフライン復旧・保存だけを実行します。
詳細は [16時停止の手順](rss-1600-stop.md) を参照。
