# スイング基準③と3つの変更案のバックテスト

検証日 2026年11月18日。2023年11月1日～2026年10月30日の選定日のうち、前回の3手法の損益がすべて確定した709回を事前に固定。新しい4手法すべてで損益を確認できた704回では、基準③が1回平均＋1,176円で最も高く、日証金条件の撤廃、5日線による延長、＋3%の当日指値はいずれも平均損益が下がった。

## 同じ704回での比較

毎回200万円・建玉ゼロから開始。1銘柄100株、費用は片道10円と売買代金の0.05%。円表示は費用控除後・税引前で四捨五入した。最大下落率は、口座全体を毎日終値で評価した際、それまでの最高資産からどれだけ下落したかを各回で求めたもの。

| 手法 | 1回平均損益 | 基準③との差 | 中央値 | 最悪の1回 | 黒字回数 | 各回の最大下落率の平均 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 基準③ | ＋1,176 | 0 | −3,219 | −74,871 | 317/704 | 1.12% |
| 日証金条件なし | −1,589 | −2,765 | −7,060 | −146,941 | 268/704 | 1.41% |
| 5日線割れまで延長 | ＋1,107 | −69 | −5,353 | −74,871 | 297/704 | 1.38% |
| ＋3%の当日指値 | ＋401 | −775 | −5,391 | −104,497 | 290/704 | 1.32% |

基準③は、20日上昇率上位のうち移動平均、売買代金、日証金の条件を満たす銘柄を選ぶ。寄付が前日終値の＋3%を超えれば見送り、買付後は選定日までのATR14の2倍下に固定した損切りを置く。期限は買付から6営業日後の寄付。3つの変更案は、この基準からそれぞれ1点だけを変更した。[前回の売買仕様と成績](swing-gap-atr-backtest-20261118.md)

基準③そのものは元の709回で平均＋1,124円・中央値−3,274円。704回の表は、全方式に値がそろう日だけで基準も再計算した。投資期間が重なるため、各回の損益を単純に足して累積リターンにはできない。

### 1. 日証金条件を外す

選定日時点の国内普通株から、当日売買代金1億円以上、終値による費用込み100株見積20万円以下、20日騰落率プラスを適用。終値＞5日線＞20日線、当日売買代金＞前5営業日平均を残し、日証金の残高と制限による除外を外した。判断日ごとに全対象を20日騰落率順（同率はコード順）に再順位付けし、上位5銘柄まで選んだ。

709回の延べ適格銘柄は、日証金ありで45,403件、日証金なしで80,751件。上位候補の並びがまったく同じ日は6回だった。707回の比較では、日証金条件を外すと平均は＋1,125円から−1,670円に低下。2024年に限ると逆の結果になった。日証金の過去分には後日取得の原本を含み、当時の版を完全には復元できない。

### 2. 期限で利益がある銘柄を5日線割れまで延長する

基準③の期限の寄付で「始値が生の買値を上回る」かつ「前日終値が前日までの5日線を上回る」ときに延長する。固定ストップを維持し、終値が5日線を厳密に下回ったら翌営業日の寄付で決済する。上限は添付の指定どおり選定日から20立会日後の寄付（買付日を1日目として20日目）。データ末尾での強制決済は行わない。

基準で期限まで残った延べ2,145件中840件を延長した。期限の始値を見てその同じ寄付で売るか決める結果は仮定上の比較になる。そこで、利益判定も前日終値で完了させる条件を別途再生した。両方とも評価できる706回では、同日の基準③平均は＋1,176円、添付どおりが＋1,100円、前日完結の条件が＋1,001円だった。

### 3. 寄付で上限を超えた銘柄に当日限りの買い指値を残す

寄付が前日終値の1.03倍以下なら始値で買う。上回って始まった場合、同日の安値が上限以下なら上限で100株を買い、届かなければ失効。2ATRの損切りは実際のモデル買値を基準に計算し、買付当日も判定した。

従来見送った538件のうち378件が指値に到達し、160件は失効。追加の378件は97勝281敗、期限決済181件、日中の損切り177件、後日の寄付の損切り20件だった。このうち75件は買付日に損切り水準にも達した。安値が指値に完全一致したケースは0件で、指値を厳密に下回った場合のみ買っても同じ結果だった。実際の呼値、板の数量と順番、値飛びは日足から確認できない。

## 確定できなかった5つの開始日

- **2024年10月10日・11日選定、日証金なし**。REVOLUTION（8894）の株式併合で100株が10株となる。既存の100株単位の寄付・損切りモデルでは単元未満株を売れる価格を確認できず、該当する2回の口座損益を未確定とした。[株式併合と権利付最終売買日](https://search.sbisec.co.jp/v2/popwin/attention/stock/information/pop4040_240925_01.html)
- **2026年9月16日選定、5日線延長**。テクノマセマティカル（3787）を保有したまま10月1日の上場廃止を迎え、売却始値を観測できなかった。選定後に最終取引日の価格で売り直す処理は入れていない。[東証の上場廃止決定](https://www.jpx.co.jp/news/1021/20260603-23.html)
- **2026年10月23日・30日選定、5日線延長**。11月18日までの保存日足では、延長した銘柄の11月19日以降の売値が決まらなかった。確定済みの銘柄だけを足す処理は行わず、各口座を未確定とした。

## 検算と保存

取引所カレンダー上の期限を選定日＋7営業日とし、元の基準③の709口座と延べ3,532候補の状態・費用・損益を既存明細に照合した。再選定では730日分の元ルールの順位を再現し、日証金条件なしの全3,542候補の明細をもう一つの計算経路で照合した。別実装で3つの約定変更パターン（当日指値、寄付時点の延長、前日確定の延長）の銘柄別売買と確定口座の日次評価19,292件を照合した。

これは既知の履歴による1回ずつの取引シミュレーション。特に指値案と延長案の売買価格は日足からの仮定で、売買時刻、実約定、実口座での資金拘束は実測していない。

再現コードは `scripts/swing_gap_atr_variants/`、個別明細はローカルの `data/offline-verification/swing-gap-atr-variants-20261118/` に保存。combined/comparison.csv は全709回の状態と損益、paths/nav.csv は日次資産、paths/orders.csv と nojsf/orders.csv は銘柄別の明細、checks/checks.json は独立照合の結果。

以下はV1の仮想環境を使う再計算例。`<V1>` は正規リポジトリ、`<保存先>` は新しいローカルフォルダー。過去の選定順位、日証金・J-Quantsの保存原本、前回の検証記録を参照する。

```text
python -B scripts/swing_gap_atr_variants/replay_paths.py --project "<V1>" --out "<保存先>/paths"
python -B scripts/swing_gap_atr_variants/replay_without_jsf.py --project "<V1>" --out "<保存先>/nojsf"
python -B scripts/swing_gap_atr_variants/compare_variants.py --project "<V1>" --paths "<保存先>/paths/windows.csv" --no-jsf "<保存先>/nojsf/windows.csv" --out "<保存先>/combined"
python -B scripts/swing_gap_atr_variants/verify_changes.py --project "<V1>" --episodes "<V1>/data/offline-verification/swing-gap-atr-20261118/episodes" --compare "<保存先>/paths" --output "<保存先>/checks"
```
