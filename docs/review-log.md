## 発見事項と修正

| 発見した問題 | 修正 | 回帰確認 |
|---|---|---|
| HTTP試行callback属性名が不一致で取得ログが空 | on_attemptに統一 | 成功/401/429の実クライアント模擬応答とDB試行履歴 |
| 差分更新で指定下限より後の取得区間へ飛ぶ | 下限から連続した完了区間だけを前進 | 過去の穴・隣接区間・中間gap |

| 同内容では品質判定の変化を記録できない | 品質が変わった場合も検証版を追加 | error→ok→errorのPIT履歴 |
| 非有限/巨大数値で全ページが処理失敗 | Raw保持、異常タグ、数値null、品質エラー | 1e309、巨大整数、旧正常版へのfallback禁止 |

| 循環ページを拒否するとRawが残らない | Rawと取得メタデータ保存後に拒否理由を記録 | ページ本文保持、checkpoint不変 |
