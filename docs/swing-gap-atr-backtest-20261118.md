# 現行スイングと、寄付の上昇幅制限・ATR損切りの比較

2026年11月18日。各口座は現金200万円・建玉ゼロで開始。100株単位、費用控除後・税引前で比較した。

3手法すべてを評価できた709回の平均損益は、現行①が−4,624円、3条件追加②が−1,217円、提案③が＋1,124円。③と②の差は＋2,342円。寄付の上昇幅で見送った銘柄が差の主因だった。③の中央値は−3,274円。開始年や、複数日にわたって資金と建玉を引き継いだ場合の結果にはばらつきがある。

## 判定と売買

1. **① 現行**　各選定日時点の東証3市場の国内普通株から、当日売買代金1億円以上、100株の費用込み終値見積20万円以下、20営業日騰落率が正の銘柄を抽出する。騰落率降順、同率はコード昇順で上位5銘柄を翌営業日の寄付で各100株買い、買付の6営業日後の寄付で売る。
2. **② 3条件追加**　①に「終値＞5日線＞20日線」「売買代金＞直前5日平均」「日証金の融資残高と貸株残高の差が前日比で増えておらず、制限措置もない」を加え、条件を満たす銘柄から同じ基準で選ぶ。
3. **③ 提案**　②の順位を固定し、翌朝のモデル始値が前日終値の1.03倍を超える注文を失効とする。買う場合は、生の買付始値から選定日までのATR14の2倍を引いた水準に損切り価格を固定する。ATRは連続14立会日の真の値幅（高値−安値、高値と前日終値の差の絶対値、安値と前日終値の差の絶対値の最大）の単純平均。買付日の安値から判定し、後日の始値が損切り価格以下ならその始値、日中に達した場合は損切り価格で売る。期限日の寄付決済を優先する。

各約定に手数料10円と売買代金の0.05%の滑りを課した。上位5は毎日の候補数。連続口座では保有総数に5銘柄の上限を置かず、既保有銘柄の買い増しと同日買い直しを行わない。買付予定の資金は朝の売却前に確保し、見送り後の候補補充はしない。日証金入力が欠けた朝は②③の新規買いを保留する。

## 全730選定日を各回200万円から開始した結果

選定日は2023年11月1日から2026年10月30日、最後の期限決済日は11月11日。通常は各回、買付日から期限日の寄付までを観測する。共通評価709回、残り21回は権利処理、日足行、始値、評価終値の欠測などで少なくとも1手法の損益が未確定。各手法単独で確定できた回数は順に712・718・725回。以下の損益・下落率は同じ709回で比較した。

| 手法 | 1回平均損益 | 200万円に対する平均収益率 | 中央値 | 最悪の1回 | 黒字回数 | 各回最大下落率の平均 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| ① 現行 | −4,624 | -0.23% | −13,637 | −177,918 | 257/709 | 2.44% |
| ② 3条件追加 | −1,217 | -0.06% | −5,172 | −156,084 | 309/709 | 1.68% |

③が②を上回ったのは368回、同額84回、下回ったのは257回。②と③だけがそろった718回で数えても差は平均＋2,305円。連日の開始回には同じ相場・銘柄が重なるため、709回の損益の合計から累積リターンや年率は計算しない。

## 検算とデータ上の制限

- 730選定日×2基準の1,460状態、確定した1,430件の損益・最大下落率、個別7,135売買明細を保存済みの①②と照合した。提案③の差額も独立のプログラムで、同日・同銘柄の②の原明細から709回全件を再計算した。
- 取引当日の株式分割1件（5527）は公表済みの1対3の比率に合わせ、比較用の前日終値とATRを3分の1にした。比率を確認できない想定で当該選定日を未確定としても平均差の符号は同じ。 [発行会社の2025年7月15日開示](https://www2.jpx.co.jp/disc/55270/140120250714514214.pdf)
- 過去の日証金原本には2026年10月31日に遡って一括取得した版が含まれる。各選定日の朝に同じ内容が取得できたかは未確認。既知の履歴を使う回顧検証で、設定値の探索は行っていない。税・配当・実際の寄付配分は集計対象外。

## 保存と再現

ローカルの詳細は `data/offline-verification/swing-gap-atr-20261118/`。episodes の paired.csv は全730回の状態と損益、orders.csv は個別トレード、continuous の nav.csv と events.csv は日々の資産と売買、recent/recent-result.json は寄付前に保存した3日分の再生明細。個別価格・台帳・入力原本はローカル保存。

コードは `scripts/swing_gap_atr/`。V1の仮想環境を用い、下記の `<V1>` に正規プロジェクト、`<再計算先>` に新しいローカルフォルダーを指定する。再計算先と recent のファイルの親は先に作成する。データは V1 内の J-Quants 原本と既存の選定順位・ペーパー記録を参照する。

```text
python -B scripts/swing_gap_atr/replay_episodes.py --project "<V1>" --out "<再計算先>/episodes"
python -B scripts/swing_gap_atr/continuous.py --project "<V1>" --output "<再計算先>/continuous"
python -B scripts/swing_gap_atr/replay_recent.py --project "<V1>" --out "<再計算先>/recent-result.json"
python -B scripts/swing_gap_atr/reconcile_attribution.py --project "<V1>" --episodes "<再計算先>/episodes"
```
