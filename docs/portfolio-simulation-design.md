# 複合戦略の合成時系列シミュレーション

前工程の固定配分は、一つの判断時点で新規候補を計算する処理だった。
この工程では、合成時系列上で判断、次の寄付、約定、保有、保有期限による決済をつなぐ。
入力・注文履歴・現金台帳・保有・評価額・リスク判定を保存し、同じ入力から再現する。
実口座の発注機能や実市場での利益検証ではない。

## 比較条件

複合戦略と、各戦略を元の資金配分率のまま個別に動かした結果を比較する。
全実行で初期現金、時系列、価格、費用、制度、リスク上限、保有期間の設定を揃える。
個別実行では他戦略のシグナルだけを取り除き、余った資金枠を再配分しない。
この比較は「各戦略に全資金を割り当てた場合」とは異なる。
比較の結果から戦略や配分率を自動選択しない。

今回の集計は現金・純資産・総リターン・戦略別損益・費用・残存保有を対象とする。
Sharpe、CAGR、年別成績など、第2段階の指標すべてを再集計する処理はまだ接続していない。
金額はDecimalで計算し、戦略別損益合計と口座純資産の増減の残差も記録する。
許容丸め残差は通貨単位で`1e-24`とし、超えた場合は正常完了にしない。

## 時点と状態

引け後の判断から生成した候補は、同時刻の価格で約定させない。
実行時には当時の価格・費用・売買可否・流動性・在庫・余力で改めて検査する。
既存保有や未決済の売り建玉を消して次の候補に資金を渡さない。
将来の引け価格を寄付の判定へ渡さない。

初期実装は全量約定か不成立のいずれかで、部分約定を推定しない。
寄付では保有期限に達した戦略の決済を先に扱い、その後で前回判断の新規候補を検査する。
新規候補の数量は寄付で作り直さず、費用・約定価格を反映して不適合なら全量拒否する。
新規投資が止まっても、既存保有の決済を同じ新規配分制約で妨げない。
同一銘柄の寄与数量ごとに保有期限を追跡し、決済できない寄与は翌セッションへ残す。

口座は現金だけの状態から開始し、入出金は行わない。日次損失の基準は直前に完了した
引け時点の純資産、参照損失の基準はそれまでの引け純資産の最大値とする。
貸株費用は前回の終値と経過した暦日数から計算し、休日分も含める。
既知のセッション数に保有期間と決済機会が収まらない新規候補は拒否する。
決済日の価格や流動性を先読みして候補を選ぶ処理ではない。

決済不能のポジションは残し、その損益・費用・拘束資金を追跡する。
期間末の未約定注文や未決済保有も保存し、全決済済みと扱わない。
比較の`comparison_complete`は全実行が中断せず終点まで進んだことを表し、
全保有の決済や全注文の約定を意味しない。残存保有を時価評価した結果として読む。
企業行動や口座入出金など、初期対応範囲外の入力は勝手に補完しない。

## 空売りの拘束資金

新しい複合シミュレーターは固定配分判定と同じく、保有中の空売りについて
`(1 + short_additional_collateral_ratio) × 現在の時価負債`を拘束する。
市場側の`Rule.margin_ratio`は追加の自己担保率として、そのままこの比率に対応する。
既存のRule型を用いる初期範囲では追加担保率は1以上となる。
寄付の基準価格と実際の約定価格の差や手数料は、売却代金と純資産を減らし得る。
事前の候補量が上限内でも、約定後の状態を仮計算して余力・上限を再検査する必要がある。

第2段階の単純バックテストは「当初の売却代金＋追加担保率×現在の時価負債」を
拘束しており、価格変動後の扱いが異なる。既存処理の意味を変更せず、今回の比較では
複合・個別の全実行に新しい同一の計算規則を適用する。
いずれも実際の証券会社の保証金制度を再現したものではない。

## 検証の限界

合成価格・合成制度によるソフトウェアの動作検証である。
ストレス仮定、業種、相関、貸株在庫、担保率は実市場の証拠ではない。
動的な市場環境判定、最適配分探索、実際の証券会社の発注・残高照合は含まない。
実市場のPIT、上場履歴、制度、企業行動と費用の整備は引き続き必要となる。
