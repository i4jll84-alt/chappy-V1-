# 順張りスイング候補研究

2026年11月17日、成績集計前に次の研究条件を固定した。日中取得・A0-5・既存スイング4口座と独立する。原本・候補・模擬台帳はローカルの data/research/swing-screen/ に保存する。

- 現在は東証3市場の内国普通株。再編前の研究では一部・二部・マザーズ・JASDAQスタンダード／グロースを対応市場とする。各日のマスターを使用する。Aはトヨタを比較用に外し、5日データの有効性・権利・100株の購入費用を確認し、売買代金中央値上位100から値幅率中央値順に30。Bは20日騰落率が正、Cは対TOPIX20日超過が正。どちらも20日騰落率の高い順。Dは20・60日騰落率が正で終値＞20日線＞60日線かつ20日線が前日比上昇。20・60日騰落率の市場内百分位を等配分。各方式で同点はコード昇順（Aは売買代金を先に使う）。
- B～Dの売買代金中央値は20日1億円を基本とし、0・3億円も比較する。60日中央値・出来高の変動係数も設定可能。業種は当日の33業種内の中央値と順位。高騰群は5日騰落率10%以上。別に20／60日高値突破、直近5日を除くモメンタム、方向別の20日効率を評価する。対照群はBと同じ流動性十分位から当日・コードの固定ハッシュで選ぶ。
- 全期間は2017年1月4日～2026年11月16日。開発は2020年末まで、条件比較は2021～2023年、最終区間は2024年以後。保存された歴史データは既知の期間。区間を跨ぐ保有ラベルを外し、評価時に条件を選び直さない。各年を固定条件で順送りし、5・10・20営業日後の寄付を各々評価する。
- 日中・翌日の値は選定に使用しない。基準は次の始値、指値比較は前日終値の99%以下（同値タッチだけでは約定にしない）、継続比較は10:00までの受信済み上昇シグナルとその後の執行可能な売り気配。価格制限・欠損・入手不能は別記。固定保有のほか、終値の20日線割れ、取得時2ATR、前日までの高値から3ATRの追随を比較する。日足では実際の約定順序は未観測。
- 100万・300万・500万・1,000万円を独立開始。最大5銘柄、1銘柄は総資産20%・100万円の小さい額まで、同一業種2銘柄、100株単位。基本は前日終値で数量固定、翌朝資金不足なら見送り。ATRリスク上限は別比較。手数料10円＋片道0.05%、悪化試験はさらに片道0.10%。売却代金を東証営業日T+2まで拘束。現物買いのみ、税引前の価格損益。受領根拠のない配当・税・借入や配当支払額を計上しない。
- TOPIXの終値＞20日線＞60日線は上昇、逆は下降、その他は横ばい。14日ATR／終値2%以上を高変動として優先。主比較は300万円、流動性1億円、10日保有。追加比較は研究専用。取得不能・未決済・評価不能の件数を残し、好成績を自動採用しない。

## 操作方法と保存内容

共通ランチャーの「順張りスイング研究」を開き、日付と方式を選ぶ。「過去候補」は判定日時、対象数、順位、選定理由を表示する。「方式比較・バックテスト」は元本・期間・方式別成績、「模擬口座」は最新の記帳日と資産を表示する。起動中のランチャーでボタンが見えない場合は、次回の通常起動から使用できる。

通常は既存の引け後の日足保存に続いて、前日までに確定した候補の模擬売買と翌営業日の候補作成が走る。「当日候補を作成」でも同じ日次経路を使用する。当日16時30分以降、翌立会日9時前に日足の受領・照合が済んだものを初版として固定する。間に合わない場合は前向きの買いを計上しない。後日訂正は別版に残す。停止は専用データフォルダーの STOP で制御する。場中の楽天・カブコム監視銘柄は既存設定のまま。

ローカルのプロジェクト直下で実行する例。

```powershell
.\.venv\Scripts\python.exe -m trading_system.research.swing_screen status
.\.venv\Scripts\python.exe -m trading_system.research.swing_screen daily --date 2026-11-17
.\.venv\Scripts\python.exe -m trading_system.research.swing_screen paper --date 2026-11-18
.\.venv\Scripts\python.exe -m trading_system.research.swing_screen preview --date 2026-11-16 --revision
.\.venv\Scripts\python.exe -m trading_system.research.swing_screen history --history history-study02 --date 2026-11-16
.\.venv\Scripts\python.exe -m trading_system.research.swing_screen backtest --history history-study02 --result results-study02
```

条件は config/swing-screen.json に記録する。条件を変える研究はコピーした設定を history、backtest、preview の --config に渡し、新しい保存先を指定する。元本・保有日数・銘柄別上限・業種別銘柄数・許容リスク・費用を変更できる。業種の金額比率も sector_fraction で設定できる。順位や対象母集団を変える費用・流動性などの変更時は専用の履歴を作る。

- data/research/swing-screen/history-v1/ に固定条件、当日のマスター、日足・指数・決算原本の参照とハッシュ、半期別の市場データと日次候補を保存。
- 同じ親フォルダーの results-v2/結果.md が計算済みの詳細報告。portfolio.csv は全期間・既知の時系列3区間・直近10/5/3年・年別の口座損益、勝率、投資比率、決済件数。cohorts.csv は判定日等ウェイトの平均と観測不能件数。paired-ci.csv、regimes.csv、signal-regimes.csv は区間推定と相場別。concentration.parquet は銘柄・業種別の寄与。半期別に全口座の約定・日次資産・候補の評価件数と欠測理由、全期間の未約定理由を保存する。
- results-v2 は休場日の開示を次の立会日で扱い、決算後に権利変動をまたぐ比較を除外した版。旧版を保存し、基本条件を変更していない。再生照合は replay-verification-v2/verification.json に保存。受信時刻付き場中原本10日分・研究コードの指紋と再照合は audited-replay-v2/verification.json に記録。
- previews/ は後からの研究再現。daily/判定日/first.json は前向き初版。各版に全対象・除外理由・特徴量・選定理由・受領時刻・入力ハッシュ・コード版を保存する。paper/ は実際の初版に基づく日次の模擬約定・未購入理由・現金・未受渡・保有。実測原本と個別の結果はローカル保管。

## 結果の読み方と採用判断

2017年1月4日～2026年11月16日、2,410立会日、160通りを順送り。候補を選んだ日ごとの等ウェイトで、5・10・20日のすべてでA～Dの費用後平均は同期間の価格TOPIXを下回った。10日ではAが平均 +0.099%、B −0.206%、C −0.218%、D −0.201%。同期間のTOPIXとの差は順に −0.349、−0.648、−0.660、−0.611ポイント。Cは各日に全銘柄から同じ指数収益率を引くため、Bと共通する銘柄の順序は変わらない。採用基準を満たした方式・保有期間は確認できない。

300万円・10日保有の累積は費用後A −87.11%、BとC −83.69%、D −24.28%。同じ開始日の価格TOPIXは +150.98%、流動性を合わせた比較群は −8.65%。口座は未解決の権利や消失銘柄を直前評価で持ち続けるため、全期間成績は暫定。100万円・500万円・1,000万円でもDの全期間累積はマイナス。決済勝率、ドローダウン、年別、共通母集団の全数はローカル報告に記載。

Dの10日候補の平均超過は上昇相場で約 +0.07 ポイント、下降相場で約 −1.48、横ばいで約 −1.21、高変動相場でも約 −0.22ポイント。300万円口座は2018年に +50.72%、2022年に −39.87%、2023年に −44.40%。全期間の最大損失寄与銘柄はDで36040。最大5銘柄・100株単位・業種制約で一部候補だけが実現損益を左右する。Dは片道費用を0.10ポイント加算すると累積 −90.13%で、資金配分の変化を含めて結果が大きく動く。最終既知区間のD対B・10日候補平均差の95%区間もゼロを含む。相場による売買停止、Dへの切替、保有期間の選び直しを支持する結果は得られなかった。

改善検証の優先項目は、同じ初版を使った将来の候補単位の超過収益、実測気配による約定可能性、配当・権利・上場廃止時の受取と現金余力の照合。今後、条件変更を試す場合は変更理由・対象期間と比較相手を固定した別版で評価する。

## 検証範囲と制約

当時の所属市場を含むマスターを日ごとに結合し、必要日数が異なる方式には個別のデータ充足判定を行う。保存済みの現行選定原本2日分について30銘柄の並びまで一致。新規の初版と訂正を分けて翌日48口座を記帳する経路は合成データで検証した。11月17日寄付向けの新方式の初版は存在せず、11月16日引け条件の再現は研究表示に限定。将来の実測成績は未検証。

- 2016年10月から価格履歴を使い、共通評価は2017年1月開始。直近10年の初め約1.5か月は評価外。過去の一括取得価格について当日実受領時刻・後日の訂正履歴をすべて復元することはできない。
- 株式分割・併合で株数を変換できる場合は反映する。配当金額・税・支払日、端株処理や未解決権利の受取額を確定できず、配当込み・税引後の利益は未検証。資産を評価できない日と長期に残る未解決建玉を区別する。
- 指値と損切りは日足で確認できる範囲の仮定約定。受信済みの場中データがある保存日は期間末の10営業日のみで、全候補を観測していない。長期の場中継続エントリーの成績は未検証。実際の証券会社の買付余力とスリッページは未確認。
- 決算予定の履歴には空白がある。前日までの公表情報を基本にし、当日の日中開示や後から判明した予定を前日に遡って使わない。財務予想修正は開示種別で判定し、業績の推定値は生成しない。

## 動作検証の実績

外部実接続を除く全体テストは1,593件とサブテスト8件成功。実接続指定5件は対象外。研究専用の10件も個別に再実行した。Ruffの静的検査は全体で成功し、新規研究コード・テストの書式検査も成功。リポジトリ一括の書式検査は変更前からのA0-5関連2ファイルの書式差分を検出した。

2回の最終再生で日次資産、全約定、候補評価、決算前後の価格、設定・欠測集計の63ファイルがSHA-256まで一致。11月16日引けは原本4,449件から、Aの流動性上位100、Bの適格581、Cの適格817、Dの適格335を確認。上位は各30。後から研究再現した初版と訂正版の候補・順位は全方式で一致し、訂正版では適格全順位を確認できる。共通の研究画面で実データの訂正版、方式Dの理由・日足受領時刻、バックテスト、模擬口座の初回待ちを確認した。
