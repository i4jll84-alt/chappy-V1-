# TOPIX・グロース250の20日線を使ったスイング基準③の比較

2026年11月18日。フィルターを加えた4案はいずれも、基準③より1回平均の損益が低かった。4案で最も平均損益が高かったのはD（両指数とも20日線超え）で、709回中320回が稼働。Dの1回平均は＋729円、基準③は＋1,124円だった。

## 条件

前回の元の3手法の損益がすべて確定した709選定日（2023年11月1日～2026年10月30日）を固定した。各回は200万円・建玉ゼロから独立に開始する。基準③は、銘柄の20日騰落率、移動平均・売買代金・日証金の条件、寄付が前日比＋3%超なら見送り、2ATRの固定損切り、買付から6営業日後の寄付決済を使う。各約定は手数料10円、滑りは片道0.05%、税・配当は対象外。[基準③の売買ルールと元の検証](swing-gap-atr-backtest-20261118.md)

各選定日の引けで、その日を含む連続20立会日の終値平均を計算した。指数終値が20日平均を厳密に上回る日すべてを通過とし、その翌営業日から始まる買付に適用する。グロース250はJ-Quantsの価格指数0070を使用し、旧・東証マザーズ指数の期間もその同一系列で集計。TOPIXは価格指数を使用した。両指数とも709回すべてで必要な終値がそろった。[J-Quantsの指数コード表](https://jpx-jquants.com/ja/spec/idx-bars-daily/indexcodes)

## 4案の比較

金額は費用控除後の円。全709回の平均では休止回の損益・最大下落率を0とする。「休止日の基準損益」は、それらの日に基準③を実行していた場合の平均。正の値は見送った利益を表す。最大下落率は各回の終値評価による資産のピークからの下落率で、表にはその平均を示す。

| 基準③（休止なし） | 709 | 100.0% | ＋1,124 | 0 | ＋1,124 | — | −74,871 | 1.12% |

Dが稼働した320回だけを見ると平均損益は＋1,616円、平均最大下落率は1.18%。休止した389回にも基準③では平均＋720円の利益があり、全回平均は基準を395円下回った。休止回を含むDの平均最大下落率は0.53%で、稼働の少なさがこの数値に影響している。

## 期間の重なりと利用可能時点

## 照合と再現

保存済みJ-Quantsの取引カレンダーと指数原本のハッシュを確認した。TOPIX専用データと指数コード0000の終値が全対象立会日で一致。独立計算で、両指数の平均と判定、709回の日別損益と下落率、全体・年別・開始位置別の集計を照合した。元の損益と下落率は基準③の保存済みの取引と口座評価から検算した。

V1の仮想環境で次のコマンドを実行する。保存先には新しいローカルフォルダーを指定する。日別の指数値・個別損益・原本の照合記録はローカルの `data/offline-verification/swing-regime-filters-20261118/` に保存した。

```text
python -B scripts/swing_gap_atr/swing_regime_filters.py --project "<V1>" --out "<保存先>"
```

regime_summary.csv は5手法の比較、regime_by_year.csv は全4年の内訳、regime_episodes.csv は全709回の指数判定・休止理由を読み取れるフラグ・損益・下落率。regime_nonoverlap.csv は7起点の再集計、regime_index_states.csv は2指数の状態別の集計、regime_sources.json は入力ファイルの照合記録を含む。
