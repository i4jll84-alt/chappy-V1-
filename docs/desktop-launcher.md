# デスクトップの共通起動と楽天RSSシート

デスクトップの「個別株ツール 共通起動」を開く。
画面を開いただけでは取得を開始しない。「楽天証券」「カブコム」「両方」から選び、
「選択した証券会社を開始」を押す。選択は次回へ保存する。

## 楽天証券

「MARKET SPEED II」で証券アプリを開き、本人がログインする。
「楽天のExcelを開く」でローカルの `Documents/RakutenRSS/RSS接続確認.xlsx` を開く。
ExcelのRSSアドインを有効にし、「接続中・発注不可」を確認する。
共通画面の「選択した証券会社を開始」から直接取得処理へ進む。
2026-10-31に楽天専用の追加確認画面を削除した。開始前の3件のデータ検査と
日付・有効値の待機は取得プログラムが引き続き自動で行う。

シートは7203.Tの現在値・現在値詳細時刻・現在日付を表示する。
Sheet1のA1:A3だけに既存と同じRssMarket数式を配置している。
ラベルと使い方は画像なので、セル数を限定する既存の読取検査を変更しない。
銘柄や式を変更すると既存の固定対象と一致しなくなるため、この画面では変更しない。
作成時のキャッシュに株価は入れない。Excel以外の計算エンジンではRSS関数を評価できず、
`#NAME?` になる。RSSアドインを読み込んだデスクトップ版Excelで再計算する必要がある。
表示やセル読取だけを、接続や鮮度の検証成功と扱わない。

2026-10-30の新PCでは、既存の64ビットRSS本体とVBAアドインの両方を登録した。
必要なファイルは `MarketSpeed2_RSS_64bit.xll` と `MarketSpeed2_RSS_VBA.xlam`。
「マーケットスピード II」タブがない場合は、Excelの「ファイル」→「オプション」→
「アドイン」→「管理: Excelアドイン」→「設定」で両方の登録・チェックを確認する。
配布先は `%LOCALAPPDATA%/MarketSpeed2/Bin/rss`。
[楽天公式のアドイン登録手順](https://marketspeed.jp/ms2_rss/onlinehelp/ohm_001/ohm_001_04.html)
に従い、Excelのビット数に対応する本体を選ぶ。
今回、実行中Excelへの両アドインの読込後に、ユーザーがタブの表示を確認した。
通常終了・次回起動後の登録維持は未確認。
ブックの保存形式は旧版と同じ `_xll.RssMarket` にそろえ、Excelでの再保存後も
既存の読取検査が通ることを確認した。未接続時の3セルの空欄は正常な取得値ではなく、
接続待ちの状態。本人がMARKET SPEED IIへログインし、Excelの
「マーケットスピード II」タブで「接続中・発注不可」を確認してから開始する。

公式RSS構文: https://marketspeed.jp/ms2_rss/onlinehelp/ohm_002/ohm_002_03.html

## カブコム（三菱UFJ eスマート証券）

「kabuステーション」でアプリを開き、本人がログインしてAPI設定を確認する。
開始時に従来の本番用APIパスワード入力画面が出る。
パスワードは保存しない。既存の取得専用API経路を使い、注文機能は有効にしない。
前回のSTOPが残っていれば、再開の確認後、OSロックで停止済みを確かめて履歴へ退避する。

## 停止・設定

「両方の取得を停止」は両方の保存先へ停止要求を出す。強制終了せず保存・照合を待つ。
カブコムのパスワード入力画面が開いている場合は取り消して閉じる。
画面の状態はOSロックと今回起動した子プロセスで確認する。
旧PCからコピーしたstatus.jsonのrunning表示を現在の稼働とは扱わない。
共通画面を閉じる前に取得を停止する。別々の取得ウィンドウは従来どおり操作可能。

「設定」では証券アプリ本体（exe）または既存ショートカット（lnk）の場所を指定できる。
設定は `data/desktop-launcher/settings.json`。選択とアプリの場所だけを保存し、Git対象外。
取引設定 `config/brokers.toml` はpaper・実発注無効のまま維持する。
両方を選んでも、両社の取得処理・データ保存先・台帳を混ぜない。

16時停止・時間外の後処理・当日データの検査は既存処理に従う。
新しい常駐登録、予約実行、自動ログインは追加していない。
今の固定対象は7203で、これは接続確認用。銘柄選定や新しい売買戦略は追加していない。
