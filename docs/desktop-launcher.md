# デスクトップの共通起動と楽天RSSシート

画面のタブは「A・Bの稼働状況」「保有銘柄」「証券会社・データ取得」の3つ。「トレード手法」タブは削除した。A・Bの売買条件は [プランの仕様](forward-plans.md) で確認できる。

デスクトップの「個別株ツール 共通起動」を開くと、A・Bペーパー口座のプログラムも自動で起動する。追加の起動ボタンは不要のため削除した。
初期画面の「A・Bの稼働状況」にある「朝の起動だけで寄付に間に合ったか」に、朝の開始時刻、A・Bそれぞれの確定時刻、候補数が表示される。起動後はこの画面で処理状況を確認する。
起動時の確認は時刻にかかわらず実行し、準備・記帳は既存の締切と取引カレンダーに従う。すでに処理中なら重ねて起動せず、その進行状況を表示する。開いたままの場合も07:40に寄付前準備を確認する。起動できなかった場合は画面の理由を確認し、解消後にツールを開き直す。「A・Bの稼働状況」で対象寄付日、判定時刻、前夜の完了記録、朝の補完結果を確認する。未確定のときはPCを起動したまま、ネット接続を保つ。確定の締切は09:00。平日22:00にWindowsの登録タスクが日足保存・関連情報取得・A・Bの引け後処理を順に実行する。個別株ツールを開いている場合も同じ処理と完了記録を使う。22時に動けなかった場合は、翌平日朝にツールを開くと不足分を取得し、A・Bの判定・ペーパー記帳へ進む。朝と22時の処理にはCodexや証券会社へのログインは不要。[両プランの条件と朝の締切](forward-plans.md)

口座一覧でAまたはBの行を選び、「口座」「判定・処理状態」「純資産」「評価損益」「保有数」「最終評価日」「対象寄付日」の項目名を押すと、一覧の下にその項目の詳細が表示される。別の口座を選ぶと同じ項目の詳細も切り替わる。「保有数」は銘柄名・株数・取得価格・最新終値を表示し、「評価損益」は純資産から開始資金を引いた内訳を表示する。長い内容は詳細欄の縦スクロールで確認できる。

「評価損益・率」はプラスを赤の +金額（+率%）、マイナスを青の -金額（-率%）で表示する。ゼロ・未確認は通常色。一覧は損益に応じて行の文字色を変え、選択中も赤・青を維持する。詳細欄では損益の行を同じ色で表示する。口座の損益率は（純資産 − 開始資金）÷ 開始資金 × 100。金額は小数第2位まで、率は小数第2位まで表示し、符号と色は丸め前の値で判定する。

「保有銘柄」タブに、A・Bの口座別の銘柄コード・名称、株数、取得価格、現在価格、終値の日付、取得日を表示する。現在価格は検証済みの保存日足の最新終値で、保存内容を約30秒おきに再確認する。取得価格は費用を除く仮想約定価格（Bはモデル上のスリッページ込み）。分割・併合があっても取得時の価格を表示し、備考を付ける。表示は小数第3位まで。取得価格や終値の欠損は「未確認」、保有なしは0銘柄と表示する。画面の表示だけで台帳・判定・取得原本を書き換えることはない。

保有銘柄にも「評価損益・率」を表示する。損益は最新終値 × 保存済み株数 − 取得総額、率は損益 ÷ 取得総額 × 100。取得総額はAの記帳済み購入支出、Bの参照台帳版に記録された原価を使い、購入時費用を含む。まだ売却していないため売却費用は含めない。分割・併合後も元の取得総額と更新済み株数で計算し、取得時の価格と単純比較しない。取得総額・株数・終値が未確認、または保有評価日と終値日が一致しない場合は損益を「—」にし、備考に理由を表示する。横に隠れた項目は表下のスクロールバーで確認できる。

証券会社の研究データを取得する場合は、「証券会社・データ取得」で「楽天証券」「カブコム」「両方」から選び、「証券データ取得」を押す。初期値は「両方」で、次回は保存した選択を使う。
選択した各社のアプリを個別に確認し、未起動なら設定のEXEまたはショートカットから開く。すでに起動中のアプリ・研究取得は引き続き使用する。
楽天の研究用Excelも自動で開く。片社がログイン待ちでももう一社は取得できる。各社の手順は「稼働状態」の研究行に表示する。

- 楽天に「RSS接続待ち」が出たらMARKET SPEED IIのログインを確認する。ExcelのRSSが「未接続」なら押し、「接続中・発注不可」を確認する。
- カブコムに「API待ち」が出たらkabuステーションにログインしAPI設定を確認する。「入力待ち」が出たらPCの専用画面でAPIパスワードを入力する。
- 寄り前は配信準備、場中は当日分足・板の取得状況を表示する。更新が止まった場合は最新の保存時刻または分足時刻を確認する。過去の終了結果には「前回」と日時を付ける。

手動で開くボタンは、左から「MARKET SPEED II」「kabuステーション」「楽天用Excelを開く」の順に並ぶ。
取得できないときには「データが届かないとき」欄の「接続を確認（トヨタ1銘柄）」を使う。

## 夜の作業（16:30以降）

営業日の16:30以降、共通画面の「当日分を保存」を1回押す。証券会社の選択は不要。
証券アプリやExcelを閉じた状態でも、J-Quantsの日足・銘柄一覧・TOPIX・公表済み決算などを保存できる。
「稼働状態」の「夜の当日分保存」で、保存中・保存完了と日足の銘柄数・休場・失敗を確認する。
通信断では当日保存の同一リクエストを最大7回試す。復旧後は処理を続け、失敗が続けば画面に再試行方法を表示する。保存後の翌営業日候補は日足の利用可能時刻を過ぎてから選定する。
保存完了後は共通画面を閉じてよい。共通画面を開き直すと、本日分の完了記録があれば表示する。
従来の保存スクリプトが実行中の場合も、同じ行に「保存中（別の画面から実行）」と表示する。

## A0_5 順張りブレイクアウト

「稼働状態」の手法名にチェックを入れると、次の当日分保存から独立した100万円・300万円の仮想口座で並行評価する。初期状態はオフ。「予定・口座監査」で口座ごとの売り予定、買い予定、決算の確認状況、受渡拘束、決済成績を確認できる。切替前の500万円台帳は保存し、今後の約定処理には使わない。楽天・カブコムの起動やログインは不要。`data/swing-forward/STOP` と `data/a0-5-paper/STOP` を尊重する。

通常の引け判定では確定日足と運用入力を確認し、日付ごとの受領票とハッシュを保存する。比較用B口座は前夜が未確定のとき、翌立会日の09:00前に必要な入力がそろい判定を終えられた場合に朝の確定版を保存する。すでに確定した予定は再実行でも固定される。公式の始値・権利情報で寄付を照合し、通常は日足公開後に記帳する。

ローカルプロジェクト直下での操作例。

```powershell
.\.venv\Scripts\python.exe -m trading_system.research.a0_5 status
.\.venv\Scripts\python.exe -m trading_system.research.a0_5 preview
.\.venv\Scripts\python.exe -m trading_system.research.a0_5 opening
```

プレビューは手法の選択や口座を変更しない。投資部門別の公式原本を更新する場合は `preview --refresh-flow`。決算原本を当日確認した場合は `confirm --code 72030 --scheduled YYYY-MM-DD --source "確認した原本"` で登録できる。買付予定日から3立会日以内の予定がないことを確認した場合は `--scheduled none`。同日中の訂正版を明示的に作る操作は `daily --revise`。訂正前の版も残る。各日の有効版は `status` で確認する。

日別予定・版管理台帳は `data/a0-5-paper/`、投資部門別の追加原本は `data/a0-5-inputs/` に保存する。固定履歴再現は別コマンド `python -m trading_system.research.a0_5_replay ..\kobetutoredosutairukouann` で実行し、`data/a0-5-replay/` に出力する。[仕様と受け入れ基準](a0-5-swing-integration.md)

## 停止・設定

「すべての取得を停止」は、両社の研究取得と接続確認へ停止要求を出す。強制終了せず保存・照合を待つ。
カブコムの入力画面は停止要求で自動的に閉じる。「取消」やEscでも本人が中止できる。
画面の状態はOSロックと今回起動した子プロセスで確認する。
旧PCからコピーしたstatus.jsonのrunning表示を現在の稼働とは扱わない。
共通画面を閉じる前に取得を停止する。別々の取得ウィンドウは従来どおり操作可能。

「設定」では証券アプリ本体（exe）または既存ショートカット（lnk）の場所を指定できる。
設定は `data/desktop-launcher/settings.json`。選択とアプリの場所だけを保存し、Git対象外。
取引設定 `config/brokers.toml` はpaper・実発注無効のまま維持する。
両方を選んでも、両社の取得処理・データ保存先・台帳を混ぜない。

16時停止・時間外の後処理・当日データの検査は既存処理に従う。
新しい常駐登録、予約実行、自動ログインは追加していない。
今の固定対象は7203で、これは接続確認用。銘柄選定や新しい売買戦略は追加していない。
