# スイング判断サブエージェントの履歴検証

検証日 2026年11月13日。GPT-6 Astra（高推論）の trade_decision を、過去の会話を引き継がないインスタンスとして使用した。選定日・銘柄名・銘柄コードを匿名化し、次の寄付・その後の価格・機械順位・対応表をモデルの入力から除いた。実在する銘柄の観測値を使った回顧検証である。

## 11月の継続口座

各200万円・建玉なしで現行と3条件追加を開始した。11月2日から11月11日までの7選定日について前日までの21営業日の日足・当日マスターと締切までに保存された信用情報を使い、11月4日から11月12日までの7営業日を連続で評価。初日に参照できた10月30日・11月2日の東証別信用原本を別途ハッシュと観測時刻で照合した。残り6選定日は必要な信用2時点がそろわず、追加群は新規買付を保留した。各群の仮想現金・建玉・決済期限からエージェントが最終売買を回答し、その指示を元に同じ始値・同じ費用で決済した。

## 約3年の別期間比較

2023年11月1日～2026年10月30日の全730選定日を対象とした。ここでは各期間を200万円・建玉なしから開始する。モデルが固定ルールを独立に数式化し、匿名化した全730セットを一括計算した。モデル側の原回答のハッシュと、検証側で再生成した回答のハッシュの一致を確認してから対応表を開き、原本の日足始値・終値で損益を再計算した。

| 比較項目 | 現行ルール | 3条件追加 |
|---|---:|---:|
| 上位候補の順位が機械判定と一致 | 730／730 | 730／730 |
| 延べ買い候補数 | 3,650 | 3,637 |
| 両ルールで損益を確定できた709期間の平均損益 | −4,624円 | −1,217円 |
| 同じルールの機械判定との平均損益差 | 0円 | 0円 |

片方以上で損益未確定の21期間（権利や価格欠損）は、順位の照合に含め、両群共通の平均損益から除いた。日証金の過去731営業日分は2026年10月31日の一括取得で、当時の版・発表時刻は未確認。保有期間は重複し、平均損益を足して3年間の連続運用成績とは扱えない。730回はモデルが作成した同じ判定プログラムの一括試験であり、730回の独立したモデル呼び出しではない。過去成績はすでに研究済みで、匿名化しても未知期間の試験にはならない。

事前に固定された条件、同じ費用、同じ売買可能枠で比較した今回の結果から確認できたのは、エージェントが既存ルールを再現したこと。追加利益は観測されなかった。寄り前の観測・台帳継続・障害時の判断は [前向きペーパー比較](swing-forward.md) で別に記録する。
