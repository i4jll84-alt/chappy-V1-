# 基準③の連続口座で同時保有を5・8・10銘柄に制限した結果

2023年11月1日引けから2026年11月18日引けまで、資金200万円・保有ゼロで開始し、741営業日の日次損益をつないだ。指定の3案で累積損益が最も大きかったのは10銘柄の＋360,116円、最大下落率が最も小さかったのは5銘柄の−20.39%だった。8銘柄は＋55,630円・−25.25%だった。すべて手数料・スリッページ控除後、税引前。期末保有分は終値評価した。

## 売買条件とデータの扱い

- 現行スイング①は各選定日時点で東証プライム・スタンダード・グロースの国内普通株のうち、当日売買代金1億円以上、100株の費用込み見積額20万円以下、20営業日騰落率が正の銘柄を対象とする。基準③は「終値＞5日線＞20日線」「当日売買代金＞直前5日平均」「日証金の融資残と貸株残の差が前日比で増えず、制限措置なし」を加える。この条件で固定した騰落率上位5銘柄（同率はコード昇順）を全口座に共通で渡す。日々の候補数は各口座とも最大5銘柄。[現行①・②・③の比較と選定条件](swing-gap-atr-backtest-20261118.md)
- 翌朝の始値が選定日終値の1.03倍を超えれば見送る。約定は各100株、片道ごとに手数料10円と売買代金の0.05%を計上。損切りは買付始値から選定日までのATR14の2倍を引いた固定価格。買付日から安値で検査し、翌日以降の寄付で割り込んだら始値で、日中に到達したら損切り価格で売る。期限売却は買付日の6営業日後の寄付で優先する。
- 主集計では期限売却で空いた枠を使える。売却前の現金残高をその日の買付総額の上限とし、当日の売却代金は再使用しない。期限売却、順位順の買付判定、損切りの順に処理するため、当日の損切りで空く枠は翌営業日から使う。既保有の買い増し・当日売却した銘柄の買い直し・6位以下の繰り上げは行わない。地合いフィルターは適用せず、A0-5の運用設定は今回の検証対象外とした。
- 以前のV1比較で採用した、前日の見積額を順位順に予約する方式でも全期間を計算した。5・8・10・上限なしの順に＋234,101円、＋55,630円、＋406,285円、＋535,766円。現金の予約方法で一部の買付対象と後続損益が変わる。
- 過去730判定日の日証金は後日取得した履歴を使い、当時の締切時点で同じ内容が入手できたかは未確認。11月の11判定日は保存済み入力を使った。個別の短期エピソードで評価が欠けた日も連続口座の判定日に含めた。この期間は既に別の手法比較にも使用している。上限は依頼の3通りに固定した。配当・税金・板の数量・値幅制限や呼値による実際の約定可否はモデルに含めていない。

### 株式分割と上場廃止

保有中に発生した6031（1株→2株）、165A（1株→8株）、2323（1株→3株）は株数、取得単価とストップを分割比率で補正した。5527はエントリー日の権利落ちにつき比較用の前日終値とATRを3分の1にした。指定の3口座では、欠測した終値や売値を取得単価で補った件数、単元未満株を日足で売却した件数はいずれもゼロだった。[6031の開示](https://www2.jpx.co.jp/disc/60310/140120231110586263.pdf)・[165Aの開示](https://www.sbigroup.co.jp/news/pdf/group/2024/0821_a.pdf)・[2323の開示](https://www.fonfun.co.jp/wp-content/uploads/2026/01/2026011401.pdf)・[5527の開示](https://www2.jpx.co.jp/disc/55270/140120250714514214.pdf)

上限なし口座はルーデンHD（1400）を2023年12月27日に96円で100株買い、上場廃止後まで保有した。添付コードに従い、2024年1月4日・5日・9日は取得単価で評価、1月10日は同じ96円で仮決済した。実際の売却・回収額は未確認。5・8・10銘柄口座は12月28日に119円で買い、最終売買日の29日に日足上で損切りとなった。4口座とも補完を必要としない12月29日引けまでの損益は、5・8・10・上限なしの順に−44,859円、−109,305円、−90,651円、−107,940円。[JPXの上場廃止決定](https://www.jpx.co.jp/news/1023/20231129-11.html)

上限なし口座について、1月10日の回収額をゼロ、処分手数料もゼロと置き、その後の全取引を再計算すると最終損益は＋756,276円となった。取得単価での仮決済から75,898円増えたのは、その後の買付が変わったため。取得単価の仮決済ケースだけで買った取引が35件、回収ゼロのケースだけで買った取引が37件あった。

## 照合・再現

主集計は、添付コードを用いた独立計算と全期間・11月開始の両方で照合した。4口座の3,008件の日別評価と10,926件の売買が一致し、資産評価額の最大差は浮動小数の丸めによる0.000000003円未満だった。上限なしの回収ゼロケースも741日分の評価と4,311件のイベントを照合した。

ローカルの保存先は `data/offline-verification/swing-position-caps-20261118/`。主要比較は `cap_comparison.csv`、年別は `cap_by_year.csv`、取引の差は `cap_trade_difference.csv`、資産推移は `cap-nav.png`。全口座の日次資産・個別売買・例外処理はそれぞれ `nav.csv`、`events.csv`、`exceptions.csv`。入力資料の識別情報を `inputs.json` に保存した。
